About the Project

p2p-chess is a decentralized, serverless multiplayer chess game. By utilizing peer-to-peer (P2P) technology, players can connect and play chess directly with each other without relying on a centralized game server to broker the matches.

The project uses PeerJS for handling the connections.

The project uses hcg-toast for toast.

The project uses the classicCburnett icons as graphics.

Key Features

  • Direct P2P Connections
  • Minimal size
  • Quick to play
